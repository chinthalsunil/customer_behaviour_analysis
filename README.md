# 📊 E-Commerce Data Analytics Project

## 1. Project Overview

This project focuses on analyzing e-commerce customer and sales data to identify meaningful business insights, understand customer purchasing behavior, and support data-driven decision-making.

The project follows an end-to-end data analytics workflow, including data loading, exploratory data analysis (EDA), data cleaning, SQL analysis, interactive dashboard development, and business reporting.

The objective is to transform raw data into actionable insights using Python, SQL, and Power BI.

## 2. Dataset

- **Dataset Name:** Customer Shopping Behavior Dataset
- **File Format:** CSV
- **Data Source:** "C:\Users\chint\OneDrive\文档\customer_shopping_behavior .xlsx"
- **Description:** Contains customer shopping information, purchasing patterns, product categories, discounts, payment methods, and transaction details.

The dataset is used to analyze customer behavior, sales performance, revenue contribution, and purchasing trends.

## 4. Project Workflow

### Step 1: Data Loading
- Imported the CSV dataset into Python using Pandas.
- Examined dataset dimensions, column names, and data types.
- Previewed records to understand the data structure.

### Step 2: Exploratory Data Analysis (EDA)
- Analyzed numerical and categorical variables.
- Identified customer purchasing patterns.
- Examined product category distribution.
- Analyzed revenue and sales trends.
- Created visualizations to identify patterns and relationships.

### Step 3: Data Cleaning & Preprocessing
- Checked for missing values and handled them appropriately.
- Identified and removed duplicate records where necessary.
- Corrected inconsistent data types.
- Standardized column names and categorical values.
- Checked for invalid and inconsistent records.
- Prepared the cleaned dataset for SQL analysis.

### Step 4: SQL Analysis
- Imported the cleaned dataset into PostgreSQL / MySQL / SQL Server.
- Performed business analysis using SQL queries.
- Used aggregate functions, filtering, grouping, sorting, and joins where applicable.
- Analyzed customer segments and product performance.
- Calculated revenue contribution across different categories.
- Identified key business trends and patterns.

### Step 5: Power BI Dashboard
- Connected Power BI to the cleaned dataset.
- Created meaningful KPIs and visualizations.
- Designed an interactive dashboard.
- Added slicers and filters for dynamic analysis.
- Highlighted important business metrics and trends.

## 8. How to Run the Project

### Prerequisites

Install the following tools:

- Python 3.x
-  Google Colab
- PostgreSQL / MySQL / SQL Server
- Power BI Desktop

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/E-Commerce-Data-Analytics.git
```

### Step 2: Navigate to the Project Folder

```bash
cd E-Commerce-Data-Analytics
```

### Step 3: Install Required Python Libraries

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy
```

Install the appropriate database connector depending on your SQL platform.

### Step 4: Run Python Notebooks

Open the notebooks folder and execute the notebooks in the following order:

1. Data Loading
2. Exploratory Data Analysis
3. Data Cleaning

### Step 5: Perform SQL Analysis

- Create a database in your preferred SQL platform.
- Import the cleaned dataset.
- Execute the SQL scripts available in the `sql/` folder.

### Step 6: Open Power BI Dashboard

- Open the `.pbix` file using Power BI Desktop.
- Configure the data source if required.
- Refresh the dataset to explore the dashboard.

### Step 7: View the Report & Presentation

Open the project report and presentation files available in their respective folders.
